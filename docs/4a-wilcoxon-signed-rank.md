# Wilcoxon Signed-Rank Test {#wilcoxon-signed-rank}

*This chapter has not been written yet.*

Non-parametric tests work on the ranks of the values instead of the values themselves, so they make fewer assumptions about the shape of the distribution. The Wilcoxon signed-rank test is the rank-based version of the one-sample and paired t-tests.
