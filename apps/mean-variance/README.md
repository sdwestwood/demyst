# Mean And Variance Widget

This is a small Shiny widget for the demystify book. It lets students change the mean and variance of a normal distribution and see how the curve shifts or spreads out.

The plot has optional layers for:

- sample dots
- lines from values to the mean
- the normal bell curve

Run from `mine/demyst` with:

```r
shiny::runApp("apps/mean-variance")
```
