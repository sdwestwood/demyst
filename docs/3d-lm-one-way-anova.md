# One-Way ANOVA as a Linear Model {#lm-one-way-anova}

*This chapter has not been written yet.*

One-way ANOVA from Chapter \@ref(one-way-anova), rebuilt with `lm()`. A predictor with three or more groups is dummy coded as a set of 0/1 variables. The F statistic is built from `my_sse()`, by comparing the model with the predictor against the model without it: the mean as a model, from Chapter \@ref(lm-mean).
