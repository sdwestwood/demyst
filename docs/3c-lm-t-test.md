# The Independent t-Test as a Linear Model {#lm-t-test}

*This chapter has not been written yet.*

The independent t-test from Chapter \@ref(two-sample-t), rebuilt with `lm()`. Group is coded as 0 and 1, so the intercept is the mean of the group coded 0 and the slope is the difference between the two group means. The slope's t-value equals the pooled independent t.
